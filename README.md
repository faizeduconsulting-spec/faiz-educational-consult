# Faiz Educational Consult

Premium educational resources e-commerce website for Faiz Educational Consult (Nigeria).

## Live site
Deploy this repository on [Vercel](https://vercel.com/new?teamSlug=faizeduconsulting) — import this repo and click Deploy.

## Features
- Product catalogue with search & filters
- Shopping cart & checkout (order via WhatsApp)
- WhatsApp integration: 0813 097 4630
- Fully responsive, mobile-friendly design
- Clean luxury educational aesthetic
